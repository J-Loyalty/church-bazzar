# 행사 당일 타임라인 (안)

이 문서는 2026년 10월 9일(금) 행사 당일의 시간표와 행사 전 준비 일정을 정리합니다.
  당일은 **새벽 예배 후(06:30경) 천막 설치로 시작해, 판매는 10:00 ~ 15:00, 판매 종료 후 약 1시간 반의 뒷정리(16:30경)로 끝납니다.**
  판매 시간은 해마다 10:00 ~ 16:00이었고, **2026년은 15:00에 판매를 종료**합니다.
  뒷정리는 준비의 **반대 순서**로 진행합니다.

`(확정 필요)`로 표시된 항목은 담당자 확인이 필요합니다.

### 천막 설치 자리

정문에서 교회를 바라보는 기준입니다.

| 위치 | 천막 수 |
|---|---|
| 오른쪽 | 2개 — 청년부(솜사탕, 커피) 1개, 젓갈류·꿀·배·김치 1개 |
| 가운데 | 3개 — 잡화 (고정) |
| 나머지 | 왼쪽 5개 — **맨 본당 쪽 2개는 식사장소**, 나머지 3개는 먹거리 부스. **정문 쪽으로 최대한 붙여 나란히** 세웁니다 |

천막은 모두 **10개**(오른쪽 2 + 가운데 3 + 왼쪽 5)입니다.
왼쪽 5개 중 식사장소 2개를 뺀 **3개가 먹거리 판매**에 쓰입니다.
먹거리 조가 여럿이므로 한 천막을 몇 조가 나눠 쓰는지는 `(확정 필요)` ([부스 배치](부스_배치.md) 참고).

### 짐 옮기기 순서

아침 식사 후 09:40까지 아래 순서로 옮깁니다.

1. **천막마다 놓을 탁자** — 물건 진열과 상품 판매대로 씁니다.
2. **성가대실 식탁** — 음식을 먹는 장소(식사장소)로 옮깁니다.
3. **옷걸이** — 본당 앞으로 옮깁니다.
4. **각 부스별 물품** — 잡화, 식사류는 전기그릴 등입니다.
5. **각 부스별 사전 준비**

### 뒷정리 순서

준비한 것의 반대 순서입니다.

1. **각 부스별 재료·도구를 원위치**하고 뒷정리합니다 (각 부스 담당자). **탁자도 원위치**합니다 (남자 장로회, 안수집사회, 서리집사, 청년부).
2. 남은 잡화는 **박스로 모아 «쉼터»로** 옮깁니다.
3. 남은 옷은 **포대에 담아 묶은 뒤 트럭에 실어 고물상으로** 보냅니다.
4. 옷걸이를 분해해 정리합니다.
5. 전체 뒷정리 (박스, 쓰레기 등).
