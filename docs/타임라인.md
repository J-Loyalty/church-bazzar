# 행사 당일 타임라인 (안)

기획안 원문 기준 전체 시간: 2026년 10월 9일(금) 07:00 ~ 16:00 (준비~마무리). **판매 종료 시각은 16:00으로 확정**되었습니다. 공식 표기는 그대로 07:00~16:00으로 두되, 정산·정리는 실제로는 16:00 이후까지 자연스럽게 이어집니다(초과 진행). 아래 16:00 이후 시간대는 그 초과분에 대한 참고용 초안입니다.

아래 시간 배분은 초안 제안이며, 실제 준비 상황에 맞춰 조정이 필요합니다. `(확정 필요)`로 표시된 항목은 담당자 확인이 필요합니다.
