# 운영 안내서

행사 책임자와 부스 담당자가 이 한 문서로 하루를 따라갈 수 있게, 2026년 행사의 준비 일정과 당일 시간표·교환권 규칙·천막 배치·맡은 일을 한곳에 모은 안내입니다.
  재정부가 하는 일(교환소 운영, 금고 계수, 마감 정산)은 자세히 다루지 않고, 부스와 책임자가 알아야 하는 만큼만 적었습니다.
  내용의 원본은 각 문서에 있습니다.
  `(확정 필요)`는 아직 정해지지 않은 것입니다.

### 기증 물품

- 교인이 기증한 물품은 행사 당일까지 접수합니다.
- 파손·오염 여부를 먼저 검수하고, **기준에 못 미치는 물품은 고물상으로 보내 폐기**합니다.
- **잡화와 의류를 뺀 모든 품목은 금액이 사전에 정해져** 있습니다. 가격을 책정하는 것은 기증받은 잡화·의류뿐이며, 시세보다 저렴하게 정하고 균일가나 할인 이벤트를 운영할 수 있습니다.
- 옷걸이 조립과 옷 모으기는 성가대실에서 2명이 약 2시간 걸렸습니다. 다음에는 남자 성도를 모아 30분 안에 끝내도록 조립 가이드 문서를 만들면 좋습니다 `(확정 필요: 제작 담당)`.

### 재료

- 먹거리 재료는 **중앙에서 구매해 각 조에 제공**합니다. 같은 재료를 여러 조가 따로 사는 중복 구매를 막기 위해서입니다.
- 기본 재료는 행사 1주 전에 사고, 중앙 구매와 예산, 담당은 **구제부 부장**이 맡습니다.
- 조에서 꼭 더 필요한 재료는 **구매한 뒤 청구**합니다. 청구의 한도와 절차는 `(확정 필요)`입니다.
- 그 밖의 재료를 각 조에 전달하는 일정 `(확정 필요)`.

### 교환권 준비

- 교환권은 **외부 인쇄 업체**에서 만듭니다. 1,000원권 약 1,100장, 5,000원권 약 550장, 10,000원권 약 550장으로 모두 9,350,000원어치입니다.
- **당일 현장에서는 추가할 수 없으므로** 수량이 모자라면 행사 전에 발주해야 합니다. **2026년 행사에서는 1,000원권 추가 인쇄를 하지 않았고, 교환권은 부족하지 않았습니다.**
- 각 부스에 아침에 줄 **초기 지급 교환권**은 2026년에 **부스마다 80,000원씩**이었습니다. 권종 구성은 기록이 없습니다 `(확정 필요)`. 수요예배 공지 때 이 금액을 함께 알릴지도 정해야 합니다.
- **전도용 교환권**은 성도가 값을 내고 사서 교회 밖 이웃에게 나눠 주는 것으로, 기존 교환권에 펀치로 구멍을 뚫어 구분합니다. 행사 전에 미리 배부할 수 있습니다.

### 행사 전에 파는 품목 — 김치

- 예약은 받지 않고, **행사 전에 실제로 구매**하게 합니다. 파는 자리에서 값을 받고 바로 물건을 줍니다.
- 입금(계좌이체)과 현금을 모두 받습니다. 13조 품목이며 행사 당일에도 13조 부스에서 팝니다.
- 이 매출은 교환권을 거치지 않으므로 **13조의 행사전 구매로 따로 집계해 정산에 적어야** 합니다. 빠뜨리면 그만큼 수익이 적게 잡힙니다.
- 판매, 판매액 합계 기록, 받은 돈(현금과 입금액)의 보관은 모두 **구제부**가 맡습니다 ([행사전 구매](행사전_구매.md) 참고).

### 홍보와 조장 공지

- 별도의 외부 홍보는 하지 않습니다. **교회 앞 현수막**(2주 전에 게시했고, 현수막과 교환권 제작 담당은 [운영 역할](운영_역할.md) 참고)과 **전도용 교환권 배부**로 갈음합니다.
- 2일 전 수요예배 때 조장을 모아 당일 시간표, 교환권 운영, 정산 방법을 공지합니다. 이 문서가 그 자료가 됩니다.

## 3. 교환권은 이렇게 돌아갑니다

이 행사는 부스마다 현금을 주고받지 않고 **교환권**으로 값을 치릅니다.
  처음 오신 분이 가장 낯설어하는 부분이므로 부스 담당자는 꼭 읽어 주세요.
  원본은 [교환권 운영](교환권_운영.md)입니다.

### 돈이 오가는 길

1. 손님이 **교환소**에서 현금이나 계좌이체로 교환권을 삽니다.
   교환소는 **정문 입구 한 곳뿐**이고, 교환권은 1,000원·5,000원·10,000원 세 가지입니다.
2. 손님이 부스에서 물건 값을 **교환권으로 냅니다.** 일부 현금도 받을 수 있습니다.
3. 부스는 거스름돈을 **교환권으로 줍니다.** 현금으로는 거슬러 주지 않습니다.
4. 손님이 남은 교환권을 현금으로 돌려받고 싶어 하면 **교환소로 안내**합니다. 부스에서는 바꿔 드리지 않습니다.
5. 마감 때 각 조는 가진 교환권과 받은 현금을 세어 **재정부**에 냅니다. 재정부가 그 숫자로 하루 매출을 확인합니다.

### 부스 담당자가 지킬 일

1. **교환권을 기본으로 받고, 현금도 받을 수 있습니다.** 받은 현금은 교환권과 섞지 말고 **따로 세어** 마감 때 함께 냅니다.
2. **거스름돈은 교환권으로만 줍니다.** 현금을 받은 건이라도 마찬가지입니다. 현금이 필요하다는 손님께는 교환소에서 바꿀 수 있다고 안내하세요.
3. **펀치 구멍이 뚫린 교환권은 전도용입니다.** 성도가 사서 교회 밖 이웃에게 나눠 주는 것으로 **외부 손님만** 쓸 수 있습니다.
   교회 성도가 내밀면 받지 말고 「전도용 교환권은 성도님은 쓸 수 없습니다」라고 안내하세요. 모든 손님에게 성도인지 묻지는 않고, 알아본 경우에만 적용합니다.
   외부 손님이 내민 것은 일반 교환권처럼 받습니다. 전도용은 현금으로 바꿔 드리지도 않습니다.
4. **거스름돈용 교환권은 아침에 한 번 받은 것이 전부입니다.** 하루 중 교환소가 채워 주지 않습니다.
   모자라면 **옆 부스와 같은 액수로만** 바꿉니다 (1,000원권 5장 ↔ 5,000원권 1장). 액수가 다르면 정산이 조용히 틀어져 나중에 찾을 수 없습니다.
5. **교환권함은 조마다 따로** 둡니다. 조끼리 한 통에 섞이면 어느 조 매출인지 되돌릴 수 없습니다.
6. **최소 1명은 자리를 꼭 지킵니다.** 판매 시간(10:00 ~ 15:00) 내내입니다.
   부스에서 교환소로 다녀오거나 거스름돈을 나중에 주는 것은 기록이 남지 않아 정산이 어긋나는 원인이 됩니다.

### 책임자가 알아 둘 것

- **정산 단위는 조**입니다. 5조처럼 한 조가 여러 품목을 맡아도 교환권 지급과 제출은 조 단위로 합니다.
- **교환소는 대사로 맞춥니다.** 아침과 저녁에 교환소의 교환권 통과 현금 금고를 세어, 팔려 나간 교환권과 받은 돈이 같은지 봅니다. 재환전은 건건이 적지 않습니다.
- **최종 수익금은 매출에서 원가를 뺀 값**입니다. 재료는 중앙에서 사서 쓰므로 재료비는 조가 아니라 공통 비용으로 잡힙니다.
- 교환소에서 교환권이 모자라면 당일 추가 인쇄가 불가능해 전 부스가 멈춥니다. 2026년에는 추가 인쇄 없이도 부족하지 않았지만, 1,000원권이 상대적으로 빠듯한 권종이므로 다음 행사에도 수량은 미리 확인합니다 ([교환권 운영](교환권_운영.md)의 «1,000원권은 몇 장이 필요한가» 참고).
- 행사 전에 판 교환권(전도용 사전 배부, 목장 쿠폰 등)은 정산에 따로 적어야 합니다. 적지 않으면 대사는 맞는데 매출만 빠집니다.
- 정산 방법은 [정산 절차](정산_절차.md), 입력 도구는 [교환권 정산 도구](../voucher-settlement/index.html)에 있습니다.

## 4. 부스 배치와 품목

### 천막 배치

정문에서 본당을 바라보는 기준이며 천막은 모두 10개입니다 ([부스 배치](부스_배치.md) 참고).
  천막을 세울 때는 정문에서 교회를 바라보는 기준이라 좌우가 반대입니다.

| 자리 | 천막 | 내용 |
|---|---|---|
| 정문 입구 | | 교환소, 그 앞에 다육이 |
| 교회 앞 마당 공터 | 없음 | 어린이 체험 부스 (게임·전시, 매년 마련) |
| 가운데 | 3개 | 잡화 (해마다 고정) |
| 본당 앞 | | 헌옷 (해마다 고정) |
| 왼쪽 | 5개 | 본당 쪽 2개는 식사장소. 이어서 판매 천막 3개 (아래 세 줄) |
| 왼쪽 판매 1번째 | 1개 | 국수, 김밥 |
| 왼쪽 판매 2번째 | 1개 | 해물전, 닭꼬치, 토스트 |
| 왼쪽 판매 3번째 | 1개 | 소떡소떡·만두, 떡볶이·순대·어묵 |
| 오른쪽 | 2개 | 한 천막은 청년부(솜사탕, 커피), 다른 한 천막은 젓갈류·꿀·배·김치 |

- 왼쪽 천막은 정문 쪽으로 최대한 붙여 나란히 세웁니다. 교회 주방은 식사장소 바로 아래입니다.
- 천막 안의 조별 자리는 정하지 않습니다. 천막 경계에 걸쳐 쓰는 부스도 있어 위 배정은 대략의 구분입니다.

| 2조 | 김밥 | 10조 | 의류 (헌옷) |
| 3조 | 해물전 | 11조 | 믹스커피, 솜사탕 |
| 4조 | 닭꼬치 | 12조 | 젓갈류 (명란·깻잎·낙지·씨앗) |
| 5조 | 떡볶이, 순대, 어묵 | 13조 | 김치 |
| 6조 | 소떡소떡, 만두 | 14조 | 잡화 (생활용품·도서·수공예품) |
| 7조 | 토스트 | 15조 | 다육이 |
| 8조 | 꿀, 배 | | |

- 올해 하지 않는 품목은 의류 2(새옷), 밑반찬, 주방제품, 버섯가루, 식혜입니다. 의류는 헌옷만 팝니다.
- 조리 기구는 국수·해물전이 가스버너, 나머지 요리 조는 전기그릴입니다. 재료는 중앙에서 사서 나눠 주고, 신선식품은 냉동창고에서 필요할 때마다 가져다 씁니다.
- 김밥은 식당에서 만들어 오고 부스에서는 판매만 합니다. 국수 육수는 주로 교회 주방에서 만듭니다. 둘 다 부스에서 부족하면 주방·식당에서 옮겨 옵니다.

## 5. 담당과 남은 일

### 공통 담당
| 담당 | 하는 일 |
|---|---|
| 시설/관리/뒷정리 | 부스 설치·관리, 행사 중 현장 관리, 종료 후 철거·정리 (장로회, 안수집사회, 남자 성도) |
| 식사 서빙 | 식사장소 운영·서빙과 그 자리 뒷정리 (청년부 형제들) |
| 전기 | 행사 전체의 전기 세팅을 한 분이 전담합니다 |
| 방송 | 방송 시스템 설치. 세팅할 수 있는 사람 누구나 맡을 수 있습니다 |
| 사진 | 행사 기록 촬영 |
| 메뉴판 | 사무실이 부스에 세울 메뉴판을 만듭니다 |
| 설거지 | 10:00부터 1시간씩 교대하며 15:00까지 진행해 마무리했습니다. 교회 주방에서 합니다 |
| 실시간 주변 청소 | 행사 중 부스 주변을 치웁니다 |
| 어린이 체험 | 아이들을 위한 별도 부스. 갑옷·무기·BB탄 총 전시와 착용, 요구르트 병 맞추기 게임. 담당은 [운영 역할](운영_역할.md) 참고 |
| 현장 순회 | **책임 담당자가 판매 시간 내내 돌아다니며** 부스마다 필요한 것이 있는지 먼저 살핍니다 |

- **현장 순회**는 부스에서 말하기 전에 필요를 알아채는 일이라 센스가 필요합니다. 부스는 자리를 비울 수 없으므로 찾아가서 묻는 것은 순회하는 쪽이 합니다. 살필 것의 예: 거스름돈용 교환권, 재료, 그릇과 수저의 회전, 쓰레기, 전기.
- 담당자 이름과 설거지·청소의 시간대별 명단은 [운영 역할](운영_역할.md)에 있습니다.
- 설거지는 15:00까지 하고 마무리했습니다. 주변 청소의 종료 시각은 `(확정 필요)`.
- 그릇·수저·젓가락은 다회용이라 씻어서 다시 부스로 보내야 합니다.
