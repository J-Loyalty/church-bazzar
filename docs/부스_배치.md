# 부스 배치

행사 당일 어느 자리에 어떤 부스가 서는지 정리합니다.
  천막은 새벽 예배 직후(06:30경), 부스 설치는 아침 식사 후 이뤄집니다 ([타임라인](타임라인.md) 참고).
  천막은 정문에서 교회를 바라보아 오른쪽 2개, 가운데 3개, 나머지는 왼쪽에 정문 쪽으로 붙여 세웁니다.

## 배치도

아래는 **2026년 행사에서 실제로 선 배치**입니다(행사 당일 확인).
배치는 해마다 조금씩 달라지지만, 잡화는 가운데, 헌옷은 본당 앞은 **해마다 고정**입니다.
방향은 모두 정문에서 본당을 바라보는 기준입니다.
도면 그림은 아직 저장소에 없습니다 `(확정 필요)`.

| 구분 | 위치 |
|---|---|
| **고정** | 잡화는 **가운데** |
| **고정** | 헌옷은 **본당 앞** |
| 2026년 | 먹거리는 **왼쪽에 전부** |
| 2026년 | **오른쪽**에는 청년부(솜사탕, 커피), 젓갈류, 꿀, 배, 김치 |
| 2026년 | **정문 입구**에 교환소, 그 **앞**에 다육이 |

- 천막 설치 자리는 [타임라인](타임라인.md)의 «천막 설치 자리» 참고.
  천막을 세우는 방향이 정문에서 교회를 바라보는 기준이라 위 표와 방향이 반대입니다. 같은 천막을 가리킬 때는 기준을 확인하세요.
- **오른쪽 천막 2개(정문에서 교회를 바라보는 기준)에 청년부(솜사탕, 커피), 젓갈류, 꿀, 배, 김치**가 들어갑니다. 위 표의 «오른쪽»과 같은 자리입니다.
  한 천막은 청년부(솜사탕, 커피), 다른 한 천막은 젓갈류·꿀·배·김치입니다.
  **가운데 천막 3개는 모두 잡화**입니다(해마다 고정).
- **왼쪽 천막은 5개**이고 그중 2개가 식사장소, 나머지 3개가 먹거리 판매입니다.
  천막은 모두 10개입니다.
  한 천막을 여러 조가 나눠 쓰고 천막 경계에 걸쳐 쓰는 부스도 있어, **천막 안의 조별 자리는 정하지 않습니다.**
- **왼쪽 줄의 2026년 순서**(본당 쪽에서 정문 쪽으로): **식사장소 2개**가 맨 본당 쪽이고, 이어서 먹거리 판매가 국수 → 김밥 → 해물전 → 닭꼬치 → 토스트 → 소떡소떡·만두 → 떡볶이·순대·어묵 순입니다.
  판매 천막 3개는 이렇게 나뉘었습니다.

### 설거지와 급수 · 배수

설거지는 **교회 주방에서 합니다**.
  야외에 설거지 자리를 따로 만들지 않습니다.

1. 방문객이 식사장소에서 식사
2. 사용한 그릇·수저·젓가락을 모음
3. 담당자가 교회 주방으로 운반
4. 주방에서 설거지

**이것으로 해결되는 것**
- 급수·배수는 주방의 기존 설비를 씁니다.
  야외 급수 배관이나 폐수 처리 계획이 따로 필요 없습니다.
- 배치도에 설거지 자리가 없던 이유가 이것입니다.
  실내이기 때문입니다.
- 온수도 주방 설비로 해결됩니다.

**주방은 식사장소 바로 아래입니다**

그릇을 멀리 나르지 않아도 되고, 나르는 길이 방문객 동선과 길게 겹치지도 않습니다.

- **운반 담당은 따로 정해져 있지 않습니다** `(확정 필요)`. 2024년에도 정해두지 않은 채 운영되었으나, 누가 맡는지 정해두면 그릇이 식사장소에 쌓이는 상황을 피할 수 있습니다.

**주방을 조리와 설거지가 함께 씁니다**

**국수 조가 교회 주방을 추가로 쓰고**, **김밥은 식당에서 만들어** 부스로 옮겨 옵니다.
  같은 주방에서 설거지도 합니다.

- **국수** — **육수는 주로 주방에서 만듭니다.**
  부스에서 육수가 부족하면 주방에서 국수 부스로 옮깁니다.
- **김밥** — 식당에서 만들어 옵니다.
  **부스에서 김밥이 부족하면 식당에서 부스로 옮깁니다.**

 다만 **2024년에 두 작업이 서로 걸리는 문제는 없었습니다.** 당시가 올해보다 품목이 많았던 것을 고려하면, 올해도 같은 방식으로 운영 가능합니다 ([과거 실적](과거_실적.md) 참고).

- **식당이 설거지하는 교회 주방과 같은 곳인지** `(확정 필요)`. 같은 곳이면 국수 조리·김밥 제조·설거지가 한 주방에서 겹칩니다.
- **부족할 때 육수(주방 → 국수 부스)와 김밥(식당 → 김밥 부스)을 누가 옮기는지** `(확정 필요)`. 옮기러 가는 동안 부스가 비므로 부스 상주 원칙과 부딪힙니다.
- **처음 물량을 부스에 두는 시각과 방법**, 김밥이 부스에 도착한 뒤 보관 방법 `(확정 필요)`.

**그릇 순환 — 다회용입니다**

그릇과 수저·젓가락은 **다회용**입니다.
  따라서 이렇게 한 바퀴 돕니다.

> 부스 → 방문객 → 식사장소 → **주방(왕복)** → 부스

주방이 실내라 왕복 시간이 붙습니다.
  **그릇 총량이 회전 속도를 정합니다.**
  모자라면 설거지가 밀리는 것이 아니라 그릇 대기로 판매가 막힙니다.

- 보유 그릇·수저·젓가락 수량 `(확정 필요)` — 행사 전에 세어두면 부족 여부를 미리 알 수 있습니다
- 국수·떡볶이·순대·어묵처럼 그릇을 쓰는 품목이 많아 수요가 한곳에 몰릴 수 있습니다

## 배치에서 짚어둘 점

배치와 상관없이 대비가 필요한 항목입니다.
  자리 배치도가 나오면 자리에 따른 점검 항목을 더합니다.

1. **교환소는 1곳이며 응대 인원 2명입니다**.
   일부 현금 결제가 가능하고 입금 확인도 패드·휴대폰으로 즉시 되므로, 대기열은 길지 않을 것으로 봅니다 ([교환권 운영](교환권_운영.md) 참고).
2. **의류는 헌옷 하나뿐입니다.**
   새옷(의류 2)은 하지 않으므로 의류 판매대 한 곳을 10조가 맡습니다.
   옷걸이 11개는 행사 1주 전에 조립해 세팅합니다 ([타임라인](타임라인.md) 참고).
3. **정산은 조 단위입니다**.
   교환권함과 초기 지급도 조마다 따로 둡니다 ([정산 절차](정산_절차.md) 참고).
