# 확인/결정 필요 사항 체크리스트

부스 배치와 인원 배정을 제외하고, 현재 문서들을 검토했을 때 아직 정해지지 않았거나 언급이 없는 항목을 모았습니다. 결정되는 대로 관련 문서에 반영하면 됩니다.

## 0. 목적과 목표 (관련: [목적_목표.md](목적_목표.md)) — 우선 결정
- [ ] 목표 수익금
- [ ] 수익금 사용처별 배분 비율 (구제 : 선교)
- [ ] 봉사 참여 성도 수 목표, 기증 물품 접수 목표량
- [ ] 지역 주민 방문 목표
- [ ] 수익 목표와 "시세 대비 저렴한 가격" 원칙이 충돌할 때의 우선순위 — [목적_목표.md](목적_목표.md)의 안 1(나눔 우선) / 안 2(기금 우선) 중 선택 필요
- [ ] 행사 후 봉사자·방문객 피드백 수집 여부

## 1. 교환권 운영 (관련: [교환권_운영.md](교환권_운영.md))
- [ ] 총 발행 한도: 하루에 최대 얼마까지 교환권을 발행할지 (현금 준비 규모와 직결)
- [ ] 교환권 실물 제작 방식: 인쇄 업체 이용 여부, 위조 방지 수단(일련번호, 도장, 특수 색지 등)
- [ ] 계좌이체 결제 확인 절차: 입금 계좌 안내 방법, 입금자명 확인 방법(실시간 확인 지연 시 대응)
- [ ] 당일 못 쓰고 남은 교환권 처리: 유효기간(당일 한정 vs 이월 가능), 고객이 가져간 미사용 교환권을 손실로 처리할지 여부
- [ ] 팔리지 않고 남은 교환권(발행 안 된 재고) 보관/폐기 방법, 내년 재사용 여부

## 1-1. 사전 구매 신청 (관련: [사전_구매_신청.md](사전_구매_신청.md)) — 과거 문제 재발 방지
- [ ] 사전 신청을 받는 품목, 접수 기간·방법·담당
- [ ] 품목별 확보 수량 확정 시점 및 기록 방법 (과거 초과 신청의 직접 원인)
- [ ] 초과 신청 방지 방식 — 안 1(수량 확정 후 선착순 마감) / 안 2(접수 후 배정) 중 선택
- [ ] 결제 방식 — 안 1(당일 교환권 결제) / 안 2(사전 선결제) 중 선택. 안 2를 택하면 정산에 별도 집계 절차 추가 필요
- [ ] 수령 장소·시간, 미수령분을 일반 판매로 전환하는 기준
- [ ] 사전 신청 배정 수량의 상한 설정 여부 (지역 주민 몫 확보)

## 2. 재무 / 현금 관리
- [ ] 교환권 부스 운영 초기 현금(잔돈) 준비 여부 및 금액
- [ ] 현금 보관·이동 방법 (금고, 이동 동선, 도난 방지)
- [ ] 최종 수익금 확정 후 승인/결재 절차 (누가 최종 확인하고 승인하는지)
- [ ] 고액 기부/구매자에 대한 기부금 영수증 발행 필요 여부

## 3. 기증 물품 관련 (관련: [바자회_기획안.md](../바자회_기획안.md) 3번)
- [ ] 물품 기증 접수 마감일 (행사 전 언제까지 받을지)
- [ ] 기증 물품 보관 장소 및 보관 기간 (행사 전날까지 어디에 쌓아둘지)
- [ ] 검수 불합격 물품 처리 방법 (반려/폐기/기증자 회수)
- [ ] 판매 안 되고 남은 물품 처리 방법 (재기증, 다음 행사 이월, 나눔단체 기부, 폐기)
- [ ] 고가/특수 물품이 있을 경우 별도 가격 책정 기준

## 4. 안전 · 위생 · 법규
- [ ] 행사 배상책임보험 가입 여부
- [ ] 응급상황 대응: 구급함 비치 위치, 안전 담당자, 인근 병원/응급실 연락처
- [ ] 먹거리 부스 관련 신고 필요 여부 (관할 보건소 등 확인)
- [ ] 화기(가스버너 등) 사용 시 화재 예방 조치, 소화기 비치 여부
- [ ] 주차장에 부스가 설치되므로, 행사 중 차량 통제/출입 동선 관리 방법
- [ ] 음향기기(예배, 안내 방송) 사용에 따른 인근 민원 대비 여부

## 5. 정산 도구 운영 방식 (관련: [정산_절차.md](정산_절차.md), [voucher-settlement/index.html](../voucher-settlement/index.html))
- [ ] **중요**: 현재 정산 도구는 데이터를 브라우저 localStorage에 저장하므로, 서로 다른 기기/브라우저에서 입력한 내용은 자동으로 합쳐지지 않습니다. 정산 데이터를 입력할 기기(또는 담당자)를 하나로 정하거나, 각 부스는 종이로 기록해 정산조가 한 기기에 취합 입력하는 방식을 정해야 합니다.
- [ ] 위 방식이 정해지면, 부스별 종이 기록 양식이 필요한지 여부

## 6. 홍보 / 공지 (관련: [바자회_기획안.md](../바자회_기획안.md) 6번)
- [ ] 홍보 시작 시점 및 마감 시점
- [ ] 교회 내부 홍보 외에 지역 주민 대상 홍보 여부 (현수막, 전단지 배포 지역 등)
- [ ] 재환전 불가 안내, 우천 시 일정 변경 등 공지가 필요할 때 사용할 채널과 시점 (문자/SNS/주보 중 무엇을 우선할지)

## 7. 현장 편의시설
- [ ] 화장실 위치 안내
- [ ] 쓰레기통/분리수거함 배치 위치
- [ ] 미아 방지 대책 (아이 동반 방문객 다수 예상 시)

## 8. 예배 및 설비
- [ ] 개회 예배용 음향장비(마이크/스피커), 좌석, 순서지 준비 여부
- [ ] 전기 사용 계획: 먹거리 부스(전열기구 등)·음향장비 전원(콘센트/발전기) 확보, 누전차단기 등 전기 안전 조치
- [ ] 설거지 봉사에 필요한 급수·배수 시설 위치 및 폐수 처리 방법
- [ ] 10월 야외 행사 특성상 기온 대비(방한 용품, 온수 등) 필요 여부
- [ ] 행사 사진/영상 촬영 계획 및 SNS 홍보 활용 시 초상권 동의 방법

## 9. 목적 가치 구현 (성도의 섬김·교제, 지역사회 이바지)
- [ ] 지역사회 이바지를 수익금 사용처(사후) 외에 행사 당일 현장에서도 구현할지 — 결정되지 않은 사안이므로 [가치_기준.md](가치_기준.md)의 안 1 / 안 2 중 선택 필요
- [ ] 봉사자 간 교제 시간을 일정에 별도로 편성할지 — [가치_기준.md](가치_기준.md) 참고, 안 1 / 안 2 중 선택 필요
