# 확인/결정 필요 사항 체크리스트

현재 문서들을 검토했을 때 아직 정해지지 않았거나 언급이 없는 항목을 모았습니다. 결정되는 대로 관련 문서에 반영하면 됩니다.

배치도가 확정되면서 11번(부스 배치)이 새로 생겼습니다. 조별 인원 명단 배정은 이 목록에 포함하지 않습니다.

## 0. 목적과 목표 (관련: [목적_목표.md](목적_목표.md)) — 우선 결정
- [ ] 목표 수익금 10,000,000원이 2024년 실적(10,484,136원)보다 낮은데 의도된 조정인지 — 잠정 확정 상태
- [ ] 봉사 참여 성도 수 목표, 기증 물품 접수 목표량
- [ ] 지역 주민 방문 목표
- [ ] 수익 목표와 "시세 대비 저렴한 가격" 원칙이 충돌할 때의 우선순위 — [목적_목표.md](목적_목표.md)의 안 1(나눔 우선) / 안 2(기금 우선) 중 선택 필요
- [ ] 행사 후 봉사자·방문객 피드백 수집 여부

## 1. 교환권 운영 (관련: [교환권_운영.md](교환권_운영.md))

**실물 — 수량 확정 후 남은 것**
- [ ] **1,000원권 추가 발주 수량** — 1판(+5만원, 총 1,600장) / 2판(+10만원, 2,100장) / 3판(+15만원, 2,600장) 중 결정
- [ ] 부스 간 교환 시 액수가 클 때 쓸 **메모 양식**이 필요한지
- [ ] 실제 발주 판 수와 총 인쇄 비용 (한판 500장 · 5만원 기준이면 7판 약 35만원)
- [ ] 인수 시점과 보관 담당
- [ ] **추가 발주 마감 시점** — 업체 제작 기간을 역산해 언제까지 수량을 확정할지
- [ ] 2024년 현금 매출 7,077,600원 중 **현금 선매출 금액** — 필요 수량 계산의 전제 ([과거_실적.md](과거_실적.md))
- [ ] 팔리지 않고 남은 교환권(발행 안 된 재고) 보관/폐기 방법, 내년 재사용 여부

**현금 결제 병행에 따른 것**
- [ ] 부스별 **현금 매출 집계 방법** — 교환권과 섞이지 않게 따로 세어 제출하는 절차와 양식
- [ ] 현금을 어느 정도까지 받을지 기준이 있는지 (전액 현금도 가능한지)
- [ ] **교환소가 보유할 현금** — 재환전과 **부스 잔액의 현금 교환**이 모두 이 한 곳에서 나갑니다. 부스는 잔액을 교환권으로만 주므로 현금 부담이 여기로 모입니다

**재환전에 따른 것**
- [ ] 재환전에 대비해 교환소가 보유할 현금 규모

**전도용 교환권**
- [ ] 펀치 교환권으로 결제 시 **거스름돈**을 일반 교환권으로 줄지 펀치로 줄지
- [ ] 전도용 교환권을 권종별로 배부하는지, 특정 권종만 쓰는지
- [ ] 배부 시점·수량·담당
- [ ] 마감 계수 때 펀치 교환권을 분리 집계할지 (대사에는 불필요, 실적 파악용으로만)

**그 밖에**
- [ ] **조별 재료비와 공통 비용** — 정산 도구에 입력 칸은 있으나 실제 금액은 미정. 교환권 인쇄비(한판 5만원 내외)와 천막·비품 대여료 등이 공통 비용에 들어갑니다
- [ ] **1,000원권 추가 인쇄 판 수** — 교환소 보유 1,000장은 확정이고 부스 지급분은 미정입니다. 조당 30장을 가정하면 1,450장이 필요해 **350장 부족**이며, 1판(500장, 약 5만원)이면 1,600장이 됩니다. 조별 수량이 정해지면 다시 계산해야 합니다
- [ ] **조별 초기 지급 수량** — 조마다 다르게 주기로 확정. 부스별 예상 판매 규모에 따른 실제 수량 미정
- [ ] **조별 초기 지급 권종 구성** — 5,000원권을 얼마나 섞을지. 섞을수록 1,000원권은 덜 나가지만 5,000원권 판매용(550장)이 그만큼 줄어듭니다
- [ ] **부스 잔돈이 하루 중 바닥나면 어떻게 할지** — 보충을 하지 않기로 했으므로, 넉넉히 줘도 많이 판 부스는 떨어질 수 있습니다. 큰 권종만 받을지, 그래도 교환소에 다녀올지
- [ ] 당일 못 쓰고 남은 교환권 처리: 유효기간(당일 한정 vs 이월 가능)
- [ ] 위조·혼동 방지: 지난 행사 교환권이 남아 있다면 올해 것과 구분되는지

## 2. 재무 / 현금 관리
- [ ] 교환소 운영 초기 현금(잔돈) 준비 여부 및 금액
- [ ] 현금 보관·이동 방법 (금고, 이동 동선, 도난 방지)
- [ ] 최종 수익금 확정 후 승인/결재 절차 (누가 최종 확인하고 승인하는지)
- [ ] 고액 기부/구매자에 대한 기부금 영수증 발행 필요 여부

**정산 대사에서 빠져 있는 것** — 아래는 지금 구조 그대로 두면 금액이 어긋나는 지점입니다.

- [ ] **행사 전에 판 교환권의 금액** — 입력칸은 만들었고 대사 양쪽에 더하도록 했습니다. 실제 판매 금액은 배부 수량이 정해져야 나옵니다 (1번의 「배부 시점·수량·담당」과 연결)
- [ ] **마감 때 부스 현금과 교환소 금고를 섞지 않는 순서** — [타임라인](타임라인.md) 16:30~17:00에 조별 현금 제출과 교환소 금고 재계수가 같은 시간대에 잡혀 있습니다. 부스에서 걷은 현금이 금고에 들어간 뒤에 세면 「저녁 금고」가 그만큼 부풀어 대사가 깨집니다. **저녁 금고를 먼저 세어 적고 나서 부스 현금을 받는다**는 순서를 정해두어야 합니다
- [ ] **계좌이체 합계에서 당일 교환권 판매분만 골라내는 방법** — 행사전 구매 대금, 사전 판매 교환권 대금, 일반 헌금이 같은 계좌로 들어오면 패드·휴대폰의 입금 합계에 섞입니다. 입금 시각으로 자를지, 입금자명 규칙을 둘지, 계좌를 나눌지
- [ ] **재료비를 누가 먼저 내는지** — 정산 도구는 「재정 지급」 표시로 둘 다 받아 돌려드릴 금액을 따로 냅니다. 다만 **미리 사는 경우 재정에서 언제 얼마까지 지급할지**는 정해야 합니다 ([운영 역할](운영_역할.md)의 물품 담당 역할 경계와 연결)
- [ ] **돌려드릴 돈의 출처** — 교환소 금고에서 꺼내면 대사가 틀어집니다. 마감 후 지급에 쓸 현금을 따로 마련해 두어야 합니다
- [ ] **조별 현금 매출을 재정부가 다시 세는지** — 지금은 조가 적어 낸 금액을 그대로 입력합니다. 금액과 실물이 다를 때 걸러낼 장치가 없습니다
- [ ] **기타 수입을 넣을 자리** — 2024년 결산에 「기타 206,500원」이 있었습니다. 판매가 아닌 수입(현장 기부 등)이 생기면 지금 도구에는 넣을 칸이 없습니다

## 4. 안전 · 위생
- [ ] 응급상황 대응: **구급함은 사무실**에 둡니다. 안전 담당자와 인근 병원/응급실 연락처, 마당에서 사무실까지의 경로 안내는 미정
- [ ] 식품 취급자 위생 조치 (위생모·앞치마·장갑, 건강 상태 확인 필요 여부)
- [ ] **침 방지 마스크 착용 여부** — 검토하기로 했습니다. 적용 범위(조리·배식만 / 먹거리 부스 전체), 준비 수량과 담당, 장시간 착용에 따른 봉사자 부담을 함께 정해야 합니다
- [ ] 포장 판매 식품(꿀, 젓갈류, 액젓, 새우젓, 김치)의 표시 사항 필요 여부 (제조일·유통기한·원산지)
- [ ] 화기 안전 — **가스버너 사용이 확정**되었습니다. 소화기 비치 위치·개수, 천막 아래 사용 시 안전 거리, 부탄가스·LPG 보관 장소(직사광선 회피)
- [ ] 가스 사용 부스가 좌측 열에 연속으로 붙어 있어 부스 간 간격 확보가 되는지
- [ ] 주차장에 부스가 설치되므로, 행사 중 차량 통제/출입 동선 관리 방법
- [ ] 음향기기(예배, 안내 방송) 사용에 따른 인근 민원 대비 여부

## 5. 정산 도구 운영 방식 (관련: [정산_절차.md](정산_절차.md), [voucher-settlement/index.html](../voucher-settlement/index.html))
- [ ] **중요**: 현재 정산 도구는 데이터를 브라우저 localStorage에 저장하므로, 서로 다른 기기/브라우저에서 입력한 내용은 자동으로 합쳐지지 않습니다. 정산 데이터를 입력할 기기(또는 담당자)를 하나로 정하거나, 각 부스는 종이로 기록해 재정부가 한 기기에 취합 입력하는 방식을 정해야 합니다.
- [ ] 위 방식이 정해지면, 부스별 종이 기록 양식이 필요한지 여부

## 이미 정해진 것

- **전도용 교환권의 성도 사용 제한** — **명예 규칙.** 배부할 때 안내만 하고 부스에서는 확인하지 않음
- **전도용 교환권 유상·무상** — **성도가 구매**. 정산 대사식 변경 불필요
- **펀치 목적** — **성도 본인 사용 금지, 외부 손님 전용** 표시
- **기증 물품 접수 마감일** — **10월 4일(주일)** 마감, 10/5~10/8 정리 ([타임라인.md](타임라인.md))
- **홍보 방식** — 별도 외부 홍보 없음. **교회 앞 현수막 + 전도용 교환권 배부**로 갈음
- **목표 수익금** — **10,000,000원** 잠정 확정 (변경 가능, [목적_목표.md](목적_목표.md))
- **그릇 종류** — **다회용**
- **주방의 조리·설거지 경합** — 2024년에 문제 없었음. 당시가 품목이 더 많았으므로 올해도 같은 방식 가능
- **공통 담당 4개를 맡는 곳** — 시설/관리/뒷정리 **장로회·안수집사회·남자 집사**(실시간 현장 관리 포함) / 식사 서빙 **청년부**(인원 순회) / 사진 **부목사** / 교환소·정산 **재정부**(4명)
- **«쿠폰판매»와 «정산조»** — 같은 일이며 이름을 **재정부**로 통일. 교환소 운영과 마감 정산을 함께 맡음
- **설거지 시간대별 인원** — **지난 바자회와 같은 배치**(2/4/3/3/3/2, 연인원 17명)
- **설거지 담당** — **남자 집사님들이 별도로 전담.** 공통 담당 4개와는 별개
- **실시간 현장 관리** — 시설/관리/뒷정리가 설치·철거뿐 아니라 **행사 중 현장 관리까지** 맡음
- **설거지 장소와 급수·배수** — **교회 주방**에서 설거지. 주방은 **식사장소 바로 아래**라 그릇을 멀리 나르지 않습니다. 야외 설거지 자리 불필요, 급수·배수·온수는 주방 설비 사용 ([부스_배치.md](부스_배치.md))
- **쓰레기통 배치** — **부스 곳곳에 비닐봉투**로 설치. 별도 수거대 없음
- **구급함 위치** — **사무실**에 비치
- **통로 폭과 부스 간격** — **지금처럼 부스를 붙여 둠.** 해마다 같은 방식이었고 대기 줄이 통로를 막은 일은 없었음
- **조리 장소·열원·냉장 방식** — 조리는 품목별 상이(현장 버너 / 주방 조리 후 전달), 열원은 가스·전기 혼용, 냉장은 교회 냉장고 + 아이스박스, 신선식품은 냉동창고에서 소량씩 반출 ([부스_배치.md](부스_배치.md))
- **전기 용량** — 2024년에 문제가 없었으므로 같은 방식 준용
- **신선식품 상온 방치 위험** — 냉동창고 소량 반출 방식으로 해소
- **1,000원권 부족 대책** — **추가 발주.** 아침에 넉넉히 나눠주는 것으로 대신하며, 하루 중 보충과 부스 간 맞교환은 모두 하지 않음
- **교환권 권종별 인쇄 수량** — 1,000원권 1,100장 / 5,000원권 550장 / 10,000원권 550장, **9,350,000원**어치
- **인쇄 단가** — 한판(500장)당 **5만원 내외**
- **정산 도구의 빠진 칸 3개** — **조별 현금 매출 · 재환전 · 행사전 구매 매출** 입력란과 최종 수익금 계산을 도구에 추가함
- **행사 전에 판 교환권** — 전도용(펀치) 교환권은 **행사 전에 판매**함. [1 개장 전] 탭에 금액 입력칸을 두고 **대사 양쪽에 함께** 더함. 받은 대금은 **저녁 금고에 합치지 않음**
- **재료비 선지급 구분** — 조별 재료비와 공통 비용마다 **「재정 지급」 표시**를 두어, 표시하지 않은 것은 사비로 먼저 낸 것으로 보고 **「마감 후 돌려드릴 돈」**으로 따로 합산. 수익 계산에는 둘 다 원가로 들어감
- **마감 계수 순서** — **저녁 금고를 먼저 세고 나서** 부스 현금을 받음. 먼저 섞이면 「받은 돈」이 부풀어 대사가 깨짐
- **초기 지급 대상** — **판매 부스에만** 지급. 교환소는 제외되므로 조 단위 정산과 충돌 없음
- **교환권 추가 발주** — 외부 업체지만 **행사 일정 안에서 추가 발주 가능**. 단, 당일 현장 추가는 여전히 불가
- **교환권 → 현금 재환전** — **가능**. 교환소에서 처리하며 건별 기록은 하지 않음
- **수익금 사용처별 배분 비율** — **전액 구제 헌금**. 선교 기금 배분은 없음
- **부스 잔돈 보충** — **하지 않습니다.** 아침에 한 번 주는 것이 전부이며, 그만큼 넉넉히 나눠줍니다
- **초기 지급 권종** — 1,000원권 중심이되 **5,000원권도 일부 지급 가능**. 권종별 수량은 미정
- **초기 지급 수량 방식** — **조마다 다르게** 지급
