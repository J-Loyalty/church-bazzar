# 확인/결정 필요 사항 체크리스트

현재 문서들을 검토했을 때 아직 정해지지 않았거나 언급이 없는 항목을 모았습니다.
  결정되는 대로 관련 문서에 반영하면 됩니다.

배치도가 확정되면서 11번(부스 배치)이, 2026년 편성표가 확정되면서 12번(조 편성)이 새로 정리되었습니다.
  조별 명단은 [운영 역할](운영_역할.md)에 있고 이 목록에서는 다루지 않습니다.

## 0. 목적과 목표 (관련: [목적_목표.md](목적_목표.md)) — 우선 결정
- [ ] 목표 수익금 17,000,000원은 2024년 실적(10,484,136원)의 약 1.6배인데, 품목 수는 줄었습니다.
      어디서 늘릴지(원가 절감 / 수입 증가) 근거 확인 — 수입으로는 약 29,200,000원이 필요합니다
- [ ] 수익 목표와 "시세 대비 저렴한 가격" 원칙이 충돌할 때의 우선순위 — [목적_목표.md](목적_목표.md)의 안 1(나눔 우선) / 안 2(기금 우선) 중 선택 필요

## 1. 교환권 운영 (관련: [교환권_운영.md](교환권_운영.md))

**실물 — 수량 확정 후 남은 것**
- [ ] 부스 간 교환 시 액수가 클 때 쓸 **메모 양식**이 필요한지
- [ ] 실제 발주 판 수와 총 인쇄 비용 (한판 500장 · 5만원 기준이면 7판 약 35만원)
- [ ] 인수 시점과 보관 담당
- [ ] 2024년 현금 매출 7,077,600원 중 **현금 선매출 금액** — 필요 수량 계산의 전제 ([과거_실적.md](과거_실적.md))
- [ ] 팔리지 않고 남은 교환권(발행 안 된 재고) 보관/폐기 방법, 내년 재사용 여부

**현금 결제 병행에 따른 것**
- [ ] 부스별 **현금 매출 집계 방법** — 교환권과 섞이지 않게 따로 세어 제출하는 절차와 양식
- [ ] 현금을 어느 정도까지 받을지 기준이 있는지 (전액 현금도 가능한지)
- [ ] **교환소가 보유할 현금** — 재환전과 **부스 잔액의 현금 교환**이 모두 이 한 곳에서 나갑니다.
      부스는 잔액을 교환권으로만 주므로 현금 부담이 여기로 모입니다

**재환전에 따른 것**
- [ ] 재환전에 대비해 교환소가 보유할 현금 규모

**전도용 교환권**
- [ ] 펀치 교환권으로 결제 시 **거스름돈**을 일반 교환권으로 줄지 펀치로 줄지
- [ ] **성도가 펀치 교환권을 내밀었을 때** 어떻게 안내할지 — 교환소에서 일반 교환권을 사 오시게 할지, 돌려드리기만 할지.
      판매조가 성도를 알아보는 방법(명찰 등)
- [ ] 전도용 교환권을 권종별로 배부하는지, 특정 권종만 쓰는지
- [ ] 배부 시점·수량·담당
- [ ] 마감 계수 때 펀치 교환권을 분리 집계할지 (대사에는 불필요, 실적 파악용으로만)

**그 밖에**
- [ ] **중앙 구매 재료비와 공통 비용의 실제 금액** — 정산 도구에 입력 칸은 있으나 금액은 미정.
      중앙 구매 재료비, 교환권 인쇄비(한판 5만원 내외), 천막·비품 대여료 등이 공통 비용에 들어갑니다.
      조별 재료원가 칸은 조가 구매 후 청구하는 몫만 받습니다
- [ ] **조별 초기 지급 권종 구성** — 5,000원권을 얼마나 섞을지.
      섞을수록 1,000원권은 덜 나가지만 5,000원권 판매용(550장)이 그만큼 줄어듭니다
- [ ] **부스 잔돈이 하루 중 바닥나면 어떻게 할지** — 보충을 하지 않기로 했으므로, 넉넉히 줘도 많이 판 부스는 떨어질 수 있습니다.
      큰 권종만 받을지, 그래도 교환소에 다녀올지
- [ ] 당일 못 쓰고 남은 교환권 처리: 유효기간(당일 한정 vs 이월 가능)
- [ ] 위조·혼동 방지: 지난 행사 교환권이 남아 있다면 올해 것과 구분되는지

## 1-1. 행사전 구매 (관련: [행사전_구매.md](행사전_구매.md))
올해는 **예약을 받지 않고 행사 전에 일부 품목을 실제로 판매**합니다 ([행사전_구매.md](행사전_구매.md) 참고).

- [ ] 김치 판매 **장소와 담당** (20여 명 가운데 누가 돈을 받고 기록하는지)
- [ ] **입금받은 계좌가 교환소 계좌와 같은지** — 같다면 당일 계좌이체 합계에서 빼야 함
- [ ] **판매액 합계 기록 방법** — 교환권을 거치지 않으므로 13조 판매액을 따로 집계해 최종 수익금에 합산해야 함.
      입금과 현금을 나누어 적는지
- [ ] 행사전 구매분(김치 5.3kg, 약 150봉지 — 단위 확인 필요)과 **당일 13조 부스 판매분의 물량 구분**
- [ ] 행사전 구매로 내보낼 수량의 상한 설정 여부 (지역 주민 몫 확보)

## 2. 재무 / 현금 관리
- [ ] 교환소 운영 초기 현금(잔돈) 준비 여부 및 금액
- [ ] 현금 보관·이동 방법 (금고, 이동 동선, 도난 방지)
- [ ] 최종 수익금 확정 후 승인/결재 절차 (누가 최종 확인하고 승인하는지)
- [ ] 고액 기부/구매자에 대한 기부금 영수증 발행 필요 여부

**정산 대사에서 빠져 있는 것** — 아래는 지금 구조 그대로 두면 금액이 어긋나는 지점입니다.

- [ ] **행사 전에 판 교환권의 금액** — 입력칸은 만들었고 대사 양쪽에 더하도록 했습니다.
      실제 판매 금액은 배부 수량이 정해져야 나옵니다 (1번의 「배부 시점·수량·담당」과 연결)
- [ ] **마감 때 부스 현금과 교환소 금고를 섞지 않는 순서** — [타임라인](타임라인.md) 16:30~17:00에 조별 현금 제출과 교환소 금고 재계수가 같은 시간대에 잡혀 있습니다.
      부스에서 걷은 현금이 금고에 들어간 뒤에 세면 「저녁 금고」가 그만큼 부풀어 대사가 깨집니다.
      **저녁 금고를 먼저 세어 적고 나서 부스 현금을 받는다**는 순서를 정해두어야 합니다
- [ ] **계좌이체 합계에서 당일 교환권 판매분만 골라내는 방법** — 행사전 구매 대금, 사전 판매 교환권 대금, 일반 헌금이 같은 계좌로 들어오면 패드·휴대폰의 입금 합계에 섞입니다.
      입금 시각으로 자를지, 입금자명 규칙을 둘지, 계좌를 나눌지
- [ ] **조가 구매 후 청구하는 몫의 절차** — 재료는 중앙에서 사서 제공하고, 조에서 꼭 필요한 것만 사서 청구합니다.
      정산 도구는 「재정 지급」을 표시하지 않은 몫을 돌려드릴 금액으로 따로 냅니다.
      청구의 **한도, 영수증, 승인자, 지급 시점**은 아직 없습니다 (3-1번과 연결)
- [ ] **돌려드릴 돈의 출처** — 교환소 금고에서 꺼내면 대사가 틀어집니다.
      마감 후 지급에 쓸 현금을 따로 마련해 두어야 합니다
- [ ] **조별 현금 매출을 재정부가 다시 세는지** — 지금은 조가 적어 낸 금액을 그대로 입력합니다.
      금액과 실물이 다를 때 걸러낼 장치가 없습니다
- [ ] **기타 수입을 넣을 자리** — 2024년 결산에 「기타 206,500원」이 있었습니다.
      판매가 아닌 수입(현장 기부 등)이 생기면 지금 도구에는 넣을 칸이 없습니다

## 3. 기증 물품 관련 (관련: [바자회_기획안.md](../바자회_기획안.md) 3번)
- [ ] 행사 전날까지의 물품 정리 작업 담당과 시간대, 그리고 당일 접수·가격 책정 담당과 시각
- [ ] 기증 물품 보관 장소 및 보관 기간 (행사 전날까지 어디에 쌓아둘지)
- [ ] 판매 안 되고 남은 물품 처리 방법 (재기증, 다음 행사 이월, 나눔단체 기부, 폐기)
- [ ] 고가/특수 물품이 있을 경우 별도 가격 책정 기준

## 3-1. 먹거리·가공식품 취급 (관련: [판매 품목](../바자회_기획안.md)) — 품목 확정에 따른 신규
2026년 품목 21종 중 18종이 식품으로 확정되면서 새로 생긴 항목입니다.

- [ ] **중앙 구매 담당(구제부 부장)과 물품 책임 담당자(주방)의 역할 구분** — 구제부 부장이 중앙 구매·예산을 맡기로 했습니다.
      한 사람에게 부하가 몰리므로 다음 행사에는 담당을 고루 나눌 방법
- [ ] **중앙 구매의 총예산·품목별 한도 금액**과 각 조에 전달하는 시각·장소(행사 전날까지인지 당일 아침인지).
      **기본 재료는 행사 1주 전에 구매**하기로 했으므로, 그 밖에 나중에 사야 하는 재료가 무엇인지
- [ ] **행사 전 준비의 담당자** — 2주 전 조 편성 확정, 1주 전 옷걸이 조립·물품 분류, 2일 전 조장 공지를 각각 누가 맡는지.
      조장 공지 때 조별 초기 교환권 수량도 함께 알릴지
- [ ] **조별 재료 수량을 누가 어떻게 정하는지** — 각 조가 필요량을 신청하는지, 중앙이 정하는지.
      모자랄 때 쓸 수 있는 방법이 청구뿐인지
- [ ] 남는 재료의 처리 — 판매 후 남은 재료를 어떻게 하는지, 정산에서 어떻게 보는지
- [ ] 중앙 구매분을 정산에서 어떻게 볼지 — 지금 도구는 공통 비용에 항목별로 적으면 되지만 **조별 수익은 계산하지 않습니다.**
      조별로 원가를 견주고 싶다면 항목 이름에 조를 붙여 적는 방법뿐입니다
- [ ] 조리 담당 인원과 조리 시작 시각 (07:30~09:40 짐 옮기기에 포함되는지)
- [ ] **판매 종료가 15:00으로 당겨진 데 따른 조정** — 주변 청소 13~16시 교대의 종료 시각, 개장 전 교환권 배분·금고 계수 시각 ([운영_역할.md](운영_역할.md), [타임라인.md](타임라인.md))
- [ ] 전기 전담자(설거지 13:00~14:00 조장 겸임)의 겹침 여부
- [ ] **국수 부스에 육수가 부족할 때 주방에서 누가 옮기는지**, 육수 외에 주방에서 하는 일(면 삶기 등)과 처음 물량을 부스에 두는 시각
- [ ] **김밥을 만드는 식당이 설거지하는 교회 주방과 같은 곳인지** — 같은 곳이면 국수 조리·김밥 제조·설거지가 한 주방에서 겹칩니다 (2024년에는 겹침으로 인한 문제가 없었음)
- [ ] **김밥 부스에 김밥이 부족할 때 식당에서 누가 옮기는지**, 처음 물량을 옮기는 방법·시각, 부스에 둔 뒤의 보관 방법 — 옮기는 동안 부스가 비어 상주 원칙과 부딪힙니다
- [ ] 냉장·냉동 보관 설비 확보 — 김치, 젓갈류, 새우젓, 액젓, 배
- [ ] 식품 원가 대비 판매가 책정 기준 (기증 물품의 "시세 대비 저렴하게" 원칙을 그대로 적용하면 원가 미만 판매 가능)
- [ ] 판매 후 남은 식품 처리 방법 (재고 이월 불가 품목 구분)
- [ ] 품목별 예상 준비 수량
- [ ] **소떡소떡·만두**(6조 신규 품목)의 조리 방식·열원·재료 준비 담당
- [ ] **토스트**(7조 신규 품목)의 조리 방식·열원·재료 준비 담당

## 4. 안전 · 위생
- [ ] 응급상황 대응: **구급함은 사무실**에 둡니다.
      안전 담당자와 인근 병원/응급실 연락처, 마당에서 사무실까지의 경로 안내는 미정
- [ ] 식품 취급자 위생 조치 (위생모·앞치마·장갑, 건강 상태 확인 필요 여부)
- [ ] **침 방지 마스크 착용 여부** — 검토하기로 했습니다.
      적용 범위(조리·배식만 / 먹거리 부스 전체), 준비 수량과 담당, 장시간 착용에 따른 봉사자 부담을 함께 정해야 합니다
- [ ] 포장 판매 식품(꿀, 젓갈류, 액젓, 새우젓, 김치)의 표시 사항 필요 여부 (제조일·유통기한·원산지)
- [ ] 화기 안전 — 가스는 **국수·해물전 두 부스**에서만 씁니다.
      소화기 비치 위치·개수(전기그릴 부스 포함), 천막 아래 사용 시 안전 거리, 부탄가스·LPG 보관 장소(직사광선 회피)
- [ ] **국수 부스의 가스버너가 식사장소와 바로 붙어 있습니다** — 화기와 식사 공간 사이의 거리 확보
- [ ] **전기그릴의 수량과 정격 전력, 마당 콘센트·차단기 용량** — 올해는 나머지 요리 조(4·5·6·7조)가 전기그릴이라 2024년과 열원 구성이 다를 수 있습니다.
      2024년에 무엇을 썼는지 기록이 없어 「2024년에 문제 없었음」을 근거로 삼기 어렵습니다

## 12. 조 편성 (관련: [운영_역할.md](운영_역할.md)) — 2026년 편성표에 따른 신규
2026년 편성표로 1~15조, 공통 담당(시설/관리/뒷정리, 식사 서빙, 사진, 메뉴판, 교환소·정산), 설거지 6교대, 실시간 주변 청소가 정해졌고 조장·조원 명단이 채워졌습니다.

**조와 부스가 맞지 않는 지점**

**명단에서 확인할 것**
- [ ] **신홍화 님이 3조(해물전)와 6조(소떡소떡·만두)에 모두 있습니다** — 동명이인인지, 한 분이 두 조에 배정된 것인지

      같은 분이 겹쳐 배정되지 않는지, 봉사 부담이 한쪽에 몰리지 않는지
- [ ] **명단이 2명뿐인 조** (8·9·12·13·14·15조, 조장 포함) — 부스 상주가 2명이라 식사·화장실로 자리를 비우면 한 명만 남습니다.
      교대 방법
- [ ] 목장·청년부처럼 모임 단위로 적힌 조(2·5·7·10·11조)의 **실제 인원수**와 부스 상주 2명을 누가 맡는지
- [ ] 시설/관리/뒷정리, 식사 서빙의 **인원수** (재정부는 4명으로 정해짐)
- [ ] **「뒷정리」의 경계** — 식사장소 쪽 청년부, 부스·마당 쪽 시설/관리/뒷정리, 행사 중 청소는 실시간 주변 청소가 어디서 나뉘는지

**정산 단위 — 조 단위, 그에 따른 준비 사항**

**조직 체계**
- [ ] 기획안 4번의 접수/진열/판매/정산/정리 조 구분과 품목별 조 편성의 관계 — 안 1(품목 조를 기본 단위로) / 안 2(두 체계 병렬) 중 선택
- [ ] «시설/관리/뒷정리»(장로회·안수집사회·남자 성도)와 정리조·사전 준비팀을 하나로 정리할지
- [ ] 물품 책임 담당자(주방: 온유목장, 함창숙, 장옥금)가 중앙 구매까지 맡는지, 판매 품목 전반을 맡는지.

- [ ] «사진» 담당의 촬영 범위와 초상권 동의 방법 (8번과 중복)
