# 확인/결정 필요 사항 체크리스트

현재 문서들을 검토했을 때 아직 정해지지 않았거나 언급이 없는 항목을 모았습니다. 결정되는 대로 관련 문서에 반영하면 됩니다.

배치도가 확정되면서 11번(부스 배치)이 새로 생겼습니다. 조별 인원 명단 배정은 이 목록에 포함하지 않습니다.

## 0. 목적과 목표 (관련: [목적_목표.md](목적_목표.md)) — 우선 결정
- [ ] 목표 수익금 10,000,000원이 2024년 실적(10,484,136원)보다 낮은데 의도된 조정인지 — 잠정 확정 상태
- [ ] 수익금 사용처별 배분 비율 (구제 : 선교)
- [ ] 봉사 참여 성도 수 목표, 기증 물품 접수 목표량
- [ ] 지역 주민 방문 목표
- [ ] 수익 목표와 "시세 대비 저렴한 가격" 원칙이 충돌할 때의 우선순위 — [목적_목표.md](목적_목표.md)의 안 1(나눔 우선) / 안 2(기금 우선) 중 선택 필요
- [ ] 행사 후 봉사자·방문객 피드백 수집 여부

## 1. 교환권 운영 (관련: [교환권_운영.md](교환권_운영.md))

**실물 — 수량 확정 후 남은 것**
- [ ] **1,000원권 추가 발주 수량** — 1판(+5만원, 총 1,600장) / 2판(+10만원, 2,100장) / 3판(+15만원, 2,600장) 중 결정
- [ ] 부스 간 교환 시 액수가 클 때 쓸 **메모 양식**이 필요한지
- [ ] 실제 발주 판 수와 총 인쇄 비용 (한판 500장 · 5만원 기준이면 7판 약 35만원)
- [ ] 인수 시점과 보관 담당
- [ ] **추가 발주 마감 시점** — 업체 제작 기간을 역산해 언제까지 수량을 확정할지
- [ ] 2024년 현금 매출 7,077,600원 중 **현금 선매출 금액** — 필요 수량 계산의 전제 ([과거_실적.md](과거_실적.md))
- [ ] 팔리지 않고 남은 교환권(발행 안 된 재고) 보관/폐기 방법, 내년 재사용 여부

**현금 결제 병행에 따른 것**
- [ ] 부스별 **현금 매출 집계 방법** — 교환권과 섞이지 않게 따로 세어 제출하는 절차와 양식
- [ ] 현금을 어느 정도까지 받을지 기준이 있는지 (전액 현금도 가능한지)
- [ ] 부스가 보유할 거스름돈용 현금
- [ ] **교환권 부스가 보유할 현금** — 거스름돈과 재환전 지급용 (교환권 부스는 초기 지급 대상이 아님)

**재환전에 따른 것**
- [ ] 재환전 기록 양식 — 정산 도구에는 칸이 생겼으나, 현장에서 건건이 적을 종이 양식이 필요한지
- [ ] 재환전에 대비해 교환권 부스가 보유할 현금 규모
- [ ] **전도용(펀치) 교환권도 재환전 대상인지** — 성도가 사서 외부인에게 준 것이라 되돌리면 취지가 사라짐

**전도용 교환권**
- [ ] **성도 사용 제한을 어떻게 지킬지** — 안 1(명예 규칙, 부스에서 확인 안 함) / 안 2(부스에서 확인) 중 선택
- [ ] 펀치 교환권으로 결제 시 **거스름돈**을 일반 교환권으로 줄지 펀치로 줄지
- [ ] 전도용 교환권을 권종별로 배부하는지, 특정 권종만 쓰는지
- [ ] 배부 시점·수량·담당
- [ ] 마감 계수 때 펀치 교환권을 분리 집계할지 (대사에는 불필요, 실적 파악용으로만)

**그 밖에**
- [ ] 초기 지급을 조당 45장 일률로 갈지, 부스별 예상 판매 규모에 따라 달리 줄지
- [ ] 판매조가 부스를 비우지 않고 교환권을 추가로 받는 방법 (부스 상주 원칙과 충돌)
- [ ] 당일 못 쓰고 남은 교환권 처리: 유효기간(당일 한정 vs 이월 가능)
- [ ] 위조·혼동 방지: 지난 행사 교환권이 남아 있다면 올해 것과 구분되는지

## 1-1. 사전 구매 (관련: [사전_구매_신청.md](사전_구매_신청.md))
올해는 **예약을 받지 않고 행사 전에 실제로 판매**합니다. 과거의 초과 신청 문제는 구조적으로 사라졌습니다.

- [ ] 사전 구매로 파는 품목
- [ ] 판매 기간·장소·담당
- [ ] 결제 방법 (현금 / 계좌이체 / 둘 다)
- [ ] **판매액 합계 기록 방법** — 교환권을 거치지 않으므로 따로 집계해 최종 수익금에 합산해야 함
- [ ] 물건을 파는 자리에서 바로 넘길지, 당일에 찾아가게 할지
- [ ] 사전 구매분과 당일 판매분의 물량 구분 (사전에 팔린 물건이 당일 또 팔리지 않도록)
- [ ] 사전 구매로 내보낼 수량의 상한 설정 여부 (지역 주민 몫 확보)

## 2. 재무 / 현금 관리
- [ ] 교환권 부스 운영 초기 현금(잔돈) 준비 여부 및 금액
- [ ] 현금 보관·이동 방법 (금고, 이동 동선, 도난 방지)
- [ ] 최종 수익금 확정 후 승인/결재 절차 (누가 최종 확인하고 승인하는지)
- [ ] 고액 기부/구매자에 대한 기부금 영수증 발행 필요 여부

## 3. 기증 물품 관련 (관련: [바자회_기획안.md](../바자회_기획안.md) 3번)

- [ ] 고가/특수 물품이 있을 경우 별도 가격 책정 기준

## 3-1. 먹거리·가공식품 취급 (관련: [판매 품목](../바자회_기획안.md)) — 품목 확정에 따른 신규
2026년 품목 19종 중 16종이 식품으로 확정되면서 새로 생긴 항목입니다.

- [ ] 종전 목록의 생활용품·도서·수공예품을 계속 취급할지 (「잡화」가 생활용품을 대체하는지)
- [ ] 먹거리·가공식품 재료의 구매 담당과 예산 집행 방법 (기증 물품 접수 절차로는 처리되지 않음)
- [ ] 조리 담당 인원과 조리 시작 시각 (07:00~08:00 사전 작업에 포함되는지)
- [ ] 냉장·냉동 보관 설비 확보 — 김치, 젓갈류, 새우젓, 액젓, 식혜
- [ ] 식품 원가 대비 판매가 책정 기준 (기증 물품의 "시세 대비 저렴하게" 원칙을 그대로 적용하면 원가 미만 판매 가능)
- [ ] 판매 후 남은 식품 처리 방법 (재고 이월 불가 품목 구분)
- [ ] 품목별 예상 준비 수량
- [ ] 배치도에만 있는 신규 3종(밑반찬, 버섯가루, 주방제품)을 품목 목록에 편입할지

## 4. 안전 · 위생
- [ ] 응급상황 대응: 구급함 비치 위치, 안전 담당자, 인근 병원/응급실 연락처
- [ ] 식품 취급자 위생 조치 (위생모·앞치마·장갑, 건강 상태 확인 필요 여부)
- [ ] 포장 판매 식품(꿀, 젓갈류, 액젓, 새우젓, 김치)의 표시 사항 필요 여부 (제조일·유통기한·원산지)
- [ ] 화기 안전 — **가스버너 사용이 확정**되었습니다. 소화기 비치 위치·개수, 천막 아래 사용 시 안전 거리, 부탄가스·LPG 보관 장소(직사광선 회피)
- [ ] 가스 사용 부스가 좌측 열에 연속으로 붙어 있어 부스 간 간격 확보가 되는지
- [ ] 주차장에 부스가 설치되므로, 행사 중 차량 통제/출입 동선 관리 방법
- [ ] 음향기기(예배, 안내 방송) 사용에 따른 인근 민원 대비 여부

## 5. 정산 도구 운영 방식 (관련: [정산_절차.md](정산_절차.md), [voucher-settlement/index.html](../voucher-settlement/index.html))
- [ ] **중요**: 현재 정산 도구는 데이터를 브라우저 localStorage에 저장하므로, 서로 다른 기기/브라우저에서 입력한 내용은 자동으로 합쳐지지 않습니다. 정산 데이터를 입력할 기기(또는 담당자)를 하나로 정하거나, 각 부스는 종이로 기록해 정산조가 한 기기에 취합 입력하는 방식을 정해야 합니다.
- [ ] 위 방식이 정해지면, 부스별 종이 기록 양식이 필요한지 여부

## 10. 설거지·실시간 청소 운영 (관련: [운영_역할.md](운영_역할.md))
- [ ] 설거지 시간대별 인원 — 안 1(과거 배치 2/4/3/3/3/2, 연인원 17명) / 안 2(2인 1조 고정, 연인원 12명) 중 선택
- [ ] "매 시간 다른 사람" 원칙 유지 여부 (안 1 선택 시 17명 확보 가능한지)
- [ ] 설거지 봉사 대상을 남자 집사님으로 한정할지 여부
- [ ] 실시간 청소를 «시설/관리/뒷정리» 담당이 맡는지 (설치·철거만 맡는지) 및 투입 시간대·인원·청소 도구 준비 담당
- [ ] 설거지가 공통 담당 4개 중 어디에 속하는지, 별도 조인지
- [ ] **그릇 운반 담당** — 현재 정해진 바 없음. 설거지조 / «식사 서빙» / «시설/관리/뒷정리» 중 어디가 맡을지
- [ ] **보유 그릇·수저·젓가락 수량** — 다회용으로 확정. 총량이 회전 속도를 정하므로 행사 전에 세어둘 것
- [ ] 운반 왕복 시간을 감안한 설거지 교대 인원
- [ ] 올해 품목 구성이 과거와 같은지 (그릇 사용 품목이 늘면 과거 인원으로 부족할 수 있음)

## 11. 부스 배치 (관련: [부스_배치.md](부스_배치.md)) — 배치도 확정에 따른 신규
배치도가 확정되면서, 반대로 자리가 정해지지 않은 것들이 드러났습니다.

- [ ] 식사장소와 교회 주방 사이의 **운반 경로** — 방문객 동선과 겹치는 구간이 있는지 (주방 위치가 배치도에 없음)
- [ ] 식사장소의 **그릇 반납대** 설치 여부와 위치
- [ ] **냉동창고 반출 담당자** — 판매조 부스 상주 원칙과 충돌 (가지러 가는 동안 부스가 빔)
- [ ] **반출 빈도와 단위** — 잦으면 동선 부담, 많으면 상온 방치 시간 증가
- [ ] **냉동창고 위치와 부스까지의 거리** (특히 좌측 열 먹거리 부스)
- [ ] **아이스박스 개수와 얼음·아이스팩 확보량** — 판매용 냉장 품목이 좌·우측으로 나뉘어 양쪽에 필요
- [ ] 부스별로 현장 조리인지 주방 조리인지 구분, 주방 조리분의 **부스 전달 시각**
- [ ] 마당 콘센트 위치·개수 기록 (2024년에 문제가 없었으므로 용량 문제는 아니나, 처음 맡는 봉사자를 위한 기록)
- [ ] 연장선·멀티탭 확보량과 배선 경로 (통행로 횡단 시 걸림 위험)
- [ ] 화장실, 쓰레기통·분리수거함, 구급함 위치 (7번·4번과 중복)
- [ ] 통로 폭과 부스 간격 — 좌측 8개 부스가 연속이라 주문 대기 줄이 통로를 막을 수 있음
